# Code provenance and attribution

Most scripts in this repository were written for the BMI/naturalistic-viewing analyses described in the accompanying manuscript.

## TOPF-derived code

The TOPF runner is based on the public implementation of the Topography-Based Predictive Framework (TOPF) from:

<https://github.com/xuanli-ac/TOPF>

The upstream repository should be cited together with the associated TOPF publication when this code is used. The upstream repository did not expose a repository-level license file when this study repository was prepared. For that reason, the upstream `TOPF.py` implementation is not redistributed here; users should obtain it directly from the original repository.

Study-specific preprocessing, covariate, IS-RSA, movie-content, and visualization scripts are separated into their own directories to make provenance clear.
